# fast-mlx research notes

These dated notes explain fast-mlx experiments that passed public claim and privacy review. They
include negative results because a technique that fails under a comparable workload is useful
engineering evidence.

Every note is historical and scoped to the source, model, workload, hardware, and verification
described in the article. It is not a current universal performance guarantee.
