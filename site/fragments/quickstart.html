Operator quickstart

From clone to a local chat-completions response.

Exercise fast-mlx's real HTTP/JSON and HTTP/SSE surface without downloading or loading a model. The scripted backend is a transport smoke: useful, fast to inspect, and deliberately narrower than a model or performance proof.

Before you start

Three local prerequisites.

Use an Apple Silicon Mac, macOS 14 or newer, and Swift 6. No model weights are bundled.

Apple Silicon MacThe public Swift package targets native MLX-capable Macs.
macOS 14 or newerThe project does not claim support for older macOS releases.
Swift 6Confirm your active toolchain with swift --version.

Model-free smoke

Start the real transport in three steps.

Scripted mode loads no model. It binds to loopback by default and exercises the same POST /v1/chat/completions endpoint used by loaded serving.

  1. 01

    Clone the public project source

    fast-mlx is Apache-2.0; retained third-party source keeps its upstream notices.

    git clone https://github.com/bitworks-io/fast-mlx.git
cd fast-mlx
  2. 02

    Run the scripted server

    The default address is 127.0.0.1:8080 and the default scripted model name is fastmlx-scripted. Keep it running, then open another terminal for the requests below.

    swift run --package-path spike fastmlx-serve --scripted
  3. 03

    Send a JSON completion

    The current route is temperature zero and accepts n = 1. The response is an application/json chat completion with usage.

    curl http://127.0.0.1:8080/v1/chat/completions \
  -H 'content-type: application/json' \
  -d '{"model":"fastmlx-scripted","messages":[{"role":"user","content":"hello"}],"temperature":0,"n":1,"stream":false}'

Streaming

Exercise the SSE contract.

Set stream to true and keep curl's output unbuffered. The response uses text/event-stream, emits chat-completion chunks, includes terminal usage, and ends with data: [DONE].

curl -N http://127.0.0.1:8080/v1/chat/completions \
  -H 'content-type: application/json' \
  -d '{"model":"fastmlx-scripted","messages":[{"role":"user","content":"hello"}],"temperature":0,"n":1,"stream":true}'

Plan before loading

Inspect capacity without starting a service.

fastmlx-capacity prints a host profile and catalog-wide capacity table. It is a planning tool, not proof that a model fits, launches, or meets a quality or speed target.

swift run --package-path spike fastmlx-capacity

Loaded serving boundary

Read the contract before attaching a model.

Loaded serving requires an absolute model path, an explicit model identity, and explicit memory and cache limits. Inspect the current flags rather than copying an unreviewed machine configuration.

swift run --package-path spike fastmlx-serve --help

Security defaults

The server binds to loopback by default. A non-loopback bind is refused unless FASTMLX_API_KEY is configured, and configured requests require Bearer authentication.

Current API scope

The reviewed route is temperature zero with n = 1. Unsupported sampling, tool, and structured-response fields are rejected instead of silently ignored.

Know what passed

A transport smoke is not a model benchmark.

It proves that the local command can build and exercise the reviewed HTTP request, JSON response, and SSE framing paths in scripted mode. It does not prove model compatibility, output quality, capacity fit, or performance.
